# Part VI — Instrumentation

Logging token usage and cache behavior, diagnosing failure modes from traces, and the economics: what a generation session costs, phase by phase, and why context loading rather than model intelligence is where the money goes.

The intuition this produces feeds back into better specifications, which is what closes the loop between Part VI and Part II.
