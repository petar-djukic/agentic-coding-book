# What Is Agentic Coding?

*Chapter stub — being written in the open.*

Agentic coding is a skill distinct from coding: instructing, reviewing,
and correcting a code-generating agent at small scale; specifying,
verifying, and orchestrating at large scale. This chapter introduces the
autonomy levels (L0–L5) that frame the rest of the book — from
human-in-the-loop, where you are the verification layer and it does not
scale, to human-on-the-loop, where specs and verification infrastructure
carry the load and the risk moves into the black box.
