# Requirements

*Chapter stub — being written in the open.*

The spec is the source code now. Output quality is set by requirement
quality, and the failure modes of bad specs are specific and traceable.
This chapter covers where requirements come from (standards, reference
implementations, RFCs), how to write them so an agent can execute them
without guessing, and what 320,000 deleted lines taught about which
artifact to keep.
