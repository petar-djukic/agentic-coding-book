# Orchestration

*Chapter stub — being written in the open.*

One conversation cannot hold a project. Orchestration is the machinery
that carries intent across context windows: GitHub issues as the memory
between sessions, one isolated worktree per task, a planning command that
proposes work and a human who approves it. Four commands run the whole
loop; the human stays the scheduler.
